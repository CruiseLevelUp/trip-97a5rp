# 沖繩家庭旅遊網站

家庭專屬的旅遊行程網站，含：每日行程、旅行相簿、記帳、日幣換算、地圖導航。

## 怎麼修改內容？
打開 `index.html`，找到中間 `<script id="trip-data">` 這一區，裡面就是行程、相簿、匯率，照著範例改即可。

## 怎麼加照片？
1. 把照片放進 `images/` 資料夾
2. 在 `index.html` 的 `album` 清單加一行：`{ src:"images/檔名.jpg", cap:"照片說明" },`

## 隱私
- 網址不公開、不好猜，也設了 `noindex`（不被搜尋引擎收錄）
- 記帳資料只存在瀏覽器本機，不會上傳
